# Recover or reproduce a development build

Clone the repository and select the desired commit. Install the validated devkitPPC/libogc toolchain, follow README build instructions, and supply your own BIOS on the SD card. Preserve your local BIOS configuration file when updating a build.

Host checkpoints are private debugging aids and are not shipped in this repository. They depend on a matching BIOS and configuration and are not a workaround for a broken cold boot. Do not upload guest RAM, BIOS/discs or personal runtime logs to the public repository. Share only reduced diagnostic results after removing private material.
