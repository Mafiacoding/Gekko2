# Gekko2 R1374 A/B

A: R1373 resident-blend control without frequent dump writes, with new JIT budget intervals.
B: Same JIT, no frequent dump writes; new bounded native additive GX path instead of destination-texture/TEV feedback for supported GS blends.

## B graphics scope
Supported GS equation: Cs*FIX/128 + Cd, floor before addition, saturation to 0..255. Requires blend enabled, A=Cs (0), B=zero (2), C=FIX (2), D=Cd (1), FIX<=128, COLCLAMP=1, PABE=0, plus the existing resident target/depth/triangle eligibility checks. CPU shader computes exact scaled source RGB and retains original source alpha; GX blends ONE+ONE directly with EFB destination. No destination snapshot texture, TEX1 vertex channel or destination copy for this path. Unsupported resident blend states decline before source packing/target changes; existing compact/scalar fallback remains.

The old resident texture-feedback blend path is not re-enabled for other states. This is an alternative implementation for the recurring BIOS state, not proof that the exact old GPU hang cause has been found. It is still a beta and can have hardware-specific bugs. CPU still computes texture samples, STQ/TFX/filter, source shading and exact depth/alpha metadata. No full GS/VU offload or global all-JIT claim.

Source snapshot caching is invalidated before native additive shading so changes in FIX never double-scale or reuse unscaled colors. GS alpha is not used as a substitute for FIX. The R1371 cold-boot policy fix and R1372 seed-ownership fix remain.

## JIT change in both
A best-way lookup hint now covers the whole budget interval for which the same largest-fitting cached block is correct. The interval ends immediately before a larger cached length. Any owner publication/removal invalidates it. Source/mapping generation validation and guest event/retirement budgets remain unchanged. No cache relocation, no global flush, no skipped guest cycles.

Isolated linked-PPC test, 5700 variable-budget lookups: R1373=806293 PPC instructions, R1374=500292 (37.95% fewer). R1374=5500 interval shortcuts, 200 scans. This is only lookup work, NOT emulator-wide speed or Wii FPS. New log fields JIT_BUDGET_RANGES interval_hits/way_scans and GX_NATIVE_ADDITIVE draws/source_pixels/avoided_destination_copy_bytes.

## Test
Use A first, then B. Each: restart emulator, Cold Boot, same BIOS and same options (GX on, resident/Gouraud options on). Compare the same BIOS phase; save each log separately (BUILD identifies A/B even though both use R1374 filenames). A should show additive draws=0; B should show additive draws>0 when supported triangles are encountered. Compare artifacts, reaching BIOS, guest FPS and EE/s at the same phase. Do not change Fastmem/EE/cache options between A and B. ARM firmware/worker is unchanged and is not included. No diagnostic dump is generated by these builds; normal session logs remain active.

Testpaket: A_Control/boot.dol and Gekko2-R1374A.elf; B_Native_Additive/boot.dol and Gekko2-R1374B.elf. Copy one boot.dol to the normal app path; ELF can be loaded in Dolphin.

Linked PPC GPU API oracle: unsupported blend declines without draw, supported blend uses ONE+ONE, no destination CopyTex or TEX1/map1, FIX changes 20->128->0->20 update decoded colors, source alpha and GS depth metadata remain correct. GPU EFB pixels are mocked, not visually verified. JIT interval test covers exact best-way selection, owner mutation, removal and low budgets. 40 linked PPC full-state branch/delay budget-edge interpreter comparisons passed. A control GPU oracle passed. Both DOLs match ELF sections and satisfy startup/MEM1 checks; no dump writer is linked. No physical Wii/Dolphin runtime test here, no promised speedup.
