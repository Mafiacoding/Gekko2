Gekko2 is an experimental, open-source PlayStation 2 emulator built around Nintendo Wii hardware — with a custom PowerPC recompiler, Wii-native frontend and experimental GX renderer.

04 — COMPATIBILITY

Compatibility is still experimental.

Gekko2 is not yet a general-purpose playable PS2 emulator. Current work prioritizes correct BIOS behavior, CPU/JIT precision and stable rendering before broad game compatibility.

06 — INSTALLATION

Homebrew Channel ready.

Use a build produced from the source and copy the application files to your SD card. Gekko2 does not include Sony BIOS files or games.

1

Place boot.dol, meta.xml and icon.png in sd:/apps/gekko2/.

2

Put your own PS2 BIOS dump in sd:/pcsx2/bios/.

3

Optionally place ISO/BIN images in sd:/pcsx2/games/, then launch Gekko2 from HBC.
