# R1379B test build

Changes relative to R1378B:
- VIF fill UNPACK consumes only source vectors, preserving the following command.
- Payload length calculation replaces a per-vector scan with constant-time arithmetic.
- EE reads the live implemented VIF MMIO registers instead of unrelated backing RAM.
- Bounded synchronous XGKICK terminates incomplete PATH1 parser state, following
  PCSX2 GSState's BIOS incomplete-packet handling. PATH3/DMA continuation remains intact.
- Existing R1378 shared triangle edges, DATE, nearest sampling and freeze fixes retained.
- libchdr CHD DVD2048 and single data-track CD2448 support retained, with a hunk cache.
- DSI, GX native additive/fence, EE block and ARM beta build paths retained.

This does not prove missing BIOS cubes are fully corrected. Compare on physical Wii.
CHD multi-track/parent/split and monolithic files above 2 GiB remain unsupported.
No measured Wii FPS improvement is claimed.

Build: GCC16.1.0, libogc3.1.0, matching newlib/crtls, libfat-ogc2.1.0.
Validation: 48 focused native regressions; 16,777,216 payload-length combinations.
DOL section/ELF comparison and linked PPC GX-mock check are recorded separately.
Legacy tests/test_vif.c still has eight unresolved fixture/test failures and is
not part of the passing focused suite. No full BIOS or game run locally.

Reference: https://github.com/PCSX2/pcsx2/blob/master/pcsx2/GS/GSState.cpp
