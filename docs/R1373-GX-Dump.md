# R1373 GX diagnostic control

Resident blending is rejected before packing source textures, opening EFB or changing Z. Supported non-blended resident draws remain available. Compact GX and scalar GS fallbacks remain unchanged. EE/IOP/JIT/ARM settings are unchanged. This is a diagnostic comparison, not a confirmed crash fix or speed build.

Persistent graphics operation dump: sd:/pcsx2/logs/R1373-gx-dump.txt; a .bak file can retain the previous complete dump on libfat. Last 16 operations contain sequence, stage and four hex arguments. WAIT_ENTER/WAIT_DONE: a=wait reason (0 source reuse, 1 readback, 2 presentation, 3 shutdown), b=pending, c=ticks on DONE. COPY_RECT: x,y,w,h; COPY_ENTER/DONE: pointer, bytes. DRAW_ENTER: vertex count and pending. SHADED_TARGET: bp,bw,psm,scanmsk; SHADED_BBOX: signed minx,miny,maxx,maxy encoded in hex. TEXTURE_TARGET: bp,bw,x,y; TEXTURE_STATE: w,h,blend,z. RESIDENT_TARGET/STATE: bp,bw,x,y / w,h,blend,z. CPU_CHECKPOINT: EE_PC,IOP_PC,low32 EE retired,low32 IOP retired, recorded at normal log checkpoints.

Before and after waits/copies, the trace is written, flushed, fsynced and closed; a temporary-file rename preserves the earlier complete dump during writing. A backup/restore protocol handles filesystems refusing rename-over-existing. A failed write does not halt emulation. The main log reports GX_DIAGNOSTIC dump_write_ok. Hardware/controller write caches and sudden power loss can still prevent durability. This is NOT a CPU-register exception dump: the existing DSI handler is unchanged. Last saved phase localizes the wait but is not by itself proof of crash cause. SD writes add substantial diagnostic overhead; do not use FPS to judge performance.

Install boot.dol or load Gekko2-R1373.elf in Dolphin. Use the same GX settings as R1372 and Cold Boot. After a hang/return/reboot copy both the normal R1373 log and R1373-gx-dump.txt (and .bak if present), BEFORE another run overwrites them. On Dolphin use a writable virtual SD with the emulator's files. The normal log folder must be writable.

Validation: 41 native tests passed (40 prior plus dump ring/file test). Linked PPC control test verifies blended resident draw declines before any GPU draw/pending ownership, nonblended draw still accepted, alpha/depth metadata and cold-boot policy. Diagnostic file writes are mocked in the PPC test. Standalone dump test verifies real file ring wrap, enter/done persistence, replacement and failed paths. ELF/DOL section identity and startup bounds checked. Physical Wii and Dolphin runtime not tested here.

Build: DEVKITPRO=<devkitPro path> bash tools/build_r1373.sh. GCC16.1.0/libogc3.1.0. R1371 and R1372 source archive omitted build_version.h accidentally; this archive includes the restored R1373 header and the build script.
